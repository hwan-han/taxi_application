# 오아시스해커톤 스펀지밥

### Overview
> 제 2회 오아시스 해커톤: 강세이, 김윤재, 노호준, 임환석
> 아이디어 기획 및 프론트 엔드 개발 담당 / 행정 업무 및 오프라인 발표 담당
> 기여도 30%

- **같은 길, 같은 시간을 운명처럼 매칭해주는 택시어플**

### Environment

- Framework: flutter
- SDK: >=2.12.0 <3.0.0
